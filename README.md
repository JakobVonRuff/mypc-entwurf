# MYPC – Konzept-Entwurf im Apple-Stil

Konzept-Entwurf einer Produktseite für die Gaming-PC-Marke MYPC mit einem 3D-PC zum Auseinanderbauen.
**Das ist nicht die offizielle Seite von MYPC.** Die offizielle Seite ist https://mypc.de

Produktdaten, Preise und Produktfotos stammen von mypc.de (Stand 31.10.2026), die Fotos werden direkt von dort geladen.
Das 3D-Modell ist selbst gebaut (three.js) und eine vereinfachte Darstellung.

Live-Ansicht: https://jakobvonruff.github.io/mypc-entwurf/
